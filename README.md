# Dragonet

TUI file manager for the Redhot suite.

- **Language:** Java 17 LTS
- **TUI:** Lanterna 3.x
- **Target systems:** FreeBSD, OpenBSD, Debian

## Status

In development. Current phase: **V0.1.0a — foundation**.

## Build

    ./build.sh

The result is `dragonet.jar` in the project root.
